百年の孤独

Gabriel García Márquez ／ 1967

同じ名前が七世代続く一族——
「誰が誰だかわからない」という混乱そのものが、
この小説の主題になっている。

scroll
I. Arrival

世界が生まれたばかりのとき

物語は、いまだ名前すら持たないものたちに満ちた、新しい村から始まる。 ホセ・アルカディオ・ブエンディアは妻ウルスラと一族を連れ、密林を切り拓いて マコンドを建てた。 磁石、拡大鏡、錬金術——外から来る発明のたびに彼は狂喜し、夜を徹して実験する。

その熱狂は一世代で冷める。 しかし息子も、孫も、同じ熱狂を繰り返す。 名前が変わらないように、人間の性質も変わらない。

世代を重ねるほど、名前は同じまま、中身が薄れていく。
読者が「これは誰の話だったか」と迷うのは、作者の失敗ではない。
その迷いこそが、この小説の設計だ。

家族の歴史の話ではない
「忘却」と「反復」が
人間をどう滅ぼすかの話だ。
— 七世代、マコンドの興亡 —
第一世代 / Foundation
ホセ・アルカディオ・ブエンディア
密林に理想の村を建てる。錬金術に溺れ、最後はマロニエの木に縛られて死ぬ。
第二世代 / War
アウレリャノ・ブエンディア大佐
17回の反乱を起こし、17回敗れる。晩年は小さな金魚を作っては溶かして繰り返す。
第三世代 / Growth
ホセ・アルカディオ（二世）
バナナ会社の繁栄。マコンドに文明が押し寄せる。
第四世代 / Decline
アウレリャノ・セグンド
宴と浪費の人生。双子の兄弟と人生が入れ替わる。
第五世代 / Ruin
ホセ・アルカディオ（五世）
バナナ会社が去り、村が朽ちていく。雨が四年間降り続ける。
第六世代 / Memory
アウレリャノ・ブエンディア（六世）
羊皮紙の解読に没頭する。外の世界と完全に切り離される。
第七世代 / End
アウレリャノ（最後の一人）
予言書が解読された瞬間、マコンドは地上から消える。

この小説には「進歩」がない。 一族は七世代をかけて、同じ過ちを、同じ情熱で、同じように繰り返す。 戦争、愛、錬金術、孤立——何も学ばれず、何も伝わらない。

「マコンドの人々は、羊皮紙に書かれていたことを、 もう一度生きなおしているのだと気づかなかった」

ここで問われているのは、一つの家族の悲劇ではない。 人間の集団記憶がなぜ機能しないか、だ。 歴史は繰り返すと言うが、マルケスはもっと残酷な真実を描いた—— 繰り返しているという自覚すら、また失われる、と。

ウルスラだけが例外だった。 百年を超えて生き続け、「これは以前にも起きた」と知っていた。 だが彼女の死とともに、その記憶も一族から消える。 目撃者がいなくなった歴史は、歴史でなくなる。

ガルシア＝マルケスが「マジック・リアリズム」と呼ばれる手法—— 死者が歩き回り、血が路地を流れ、空から黄色い花びらが降り続ける——を使うのは、 単なる技巧ではない。 現実に起きた暴力と狂気が、あまりに大きすぎて 写実的な散文では入りきらないからだ。

1967年、コロンビア。ラテンアメリカ文学が世界に届いた瞬間。 この小説は「百年」をかけて、今もまだ読み続けられている。

予言は完結し、マコンドは消えた。
繰り返しを知っていた者も、もういない。
ガブリエル・ガルシア＝マルケス
『百年の孤独』
